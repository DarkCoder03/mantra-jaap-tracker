## 📿 About The Project

Traditional digital counters only count, but this app makes your spiritual practice **productive and consistent**. It combines a distraction-free counting interface with a calendar dashboard, visually rewarding you for completing full cycles (Malas) of your mantras.

### 🌟 Key Features

* **Multi-Mantra Support:** Add, rename, remove, and easily switch between different counters.
* **Calendar Tracking:** Navigate through past and future months to track your daily consistency.
* **Zen Visual Progress:** Strict cycle logic. The calendar only displays solid markers for completed 108-cycles—keeping the UI clean and rewarding.
* **Immersive Feedback:** Full-cycle visual glow, gentle sound alerts, and haptic feedback (where supported) upon cycle completion so you don't have to look at the screen.
* **Data Portability:** Backup and restore your chanting data easily via JSON.
* **Customizable UI:** Switch between System, Dark, or Light themes to match your preference.

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your system.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/DarkCoder03/mantra-jaap-tracker.git](https://github.com/DarkCoder03/mantra-jaap-tracker.git)


2. Navigate into the project directory:
   ```bash
   cd mantra-jaap-tracker

3. Install the dependencies:
   ```bash
   npm install

4. Start the development server:
   ```bash
   npm run dev
